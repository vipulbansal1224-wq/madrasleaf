# Madras Leaf (Madras Cafe) - Pure Vegetarian Multi-Cuisine Restaurant Website

Modern, responsive, and high-converting restaurant web application built with **Next.js 14 (App Router)**, **TypeScript**, and **Tailwind CSS** for **Madras Leaf - A Multi-Cuisine Pure Vegetarian Restaurant** located at Wave Mall, Ferozepur Road, Ludhiana.

---

## 🍽️ Key Features

- **5 Dedicated Pages:**
  - **Home (`/`):** Hero showcase, 100% Pure Veg badge, Chef's signature recommendations with live category filters, stats strip (4.8★ rating, 1,450+ diners), dining privileges (Swiggy Dineout & District.in), Ludhiana patron reviews, and quick table booking CTA.
  - **Menu (`/menu`):** Handcrafted multi-cuisine menu with category filters (South Indian Classics, North Indian & Tandoor, Indo-Chinese, Sizzlers, Thalis, Filter Kaapi & Beverages), live dish search, spice indicators, and printable PDF download notice.
  - **About Us (`/about`):** The story of authentic South Indian heritage and North Indian royal culinary craft, plantain leaf dining philosophy, pure vegetarian kitchen standards, and visual food & ambiance gallery.
  - **Table Reservation (`/reservation`):** Interactive 4-step table booking system (Party size, date picker, lunch/dinner slots, seating areas, occasion, special notes) with instant booking ID generation and WhatsApp demo confirmation.
  - **Visit & Contact (`/contact`):** Exact location at Wave Mall, Ferozepur Road, Ludhiana, interactive Google Map embed, opening hours, direct call & WhatsApp buttons, and party banquet inquiry form with FAQs.
- **Interactive Plate / Order Drawer (`CartDrawer`):** Slide-over plate drawer with real-time dish counters, 5% Restaurant GST calculation, and 1-click WhatsApp order formatting.
- **Dish Quick View Modal:** Click anywhere on a dish card to view ingredients, tags, price, and instant add-to-plate controls.
- **Responsive Navigation:** Smooth sticky header with desktop nav, mobile slide-down drawer, phone call action, and Swiggy Dineout deep links.

## 🚀 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Build for production:**
   ```bash
   npm run build
   npm run start
   ```
